# Alohub

**AI Contact Center & CPaaS platform for Vietnam.**

Alohub provides voice, messaging, AI and communication automation infrastructure for businesses and AI agents. Built for the Vietnamese market with Zalo, Vietnamese voice AI, and local telecom compliance.

## Open Source

| Repository | Description |
|-----------|-------------|
| [alohub-mcp](https://github.com/alohubvn/alohub-mcp) | MCP Server — let Claude, GPT, Gemini make calls and send messages via Alohub |
| [n8n-nodes-alohub](https://github.com/alohubvn/n8n-nodes-alohub) | 15+ n8n community nodes for voice, messaging, and automation |
| [alohub-node](https://github.com/alohubvn/alohub-node) | Node.js SDK for the Alohub REST API |
| [alohub-python](https://github.com/alohubvn/alohub-python) | Python SDK for the Alohub REST API |
| [alohub-api-examples](https://github.com/alohubvn/alohub-api-examples) | Code examples: click-to-call, IVR, webhooks, AI agent integration |

## Platform

- **Voice** — SIP trunk, WebRTC, IVR, call recording, number rotation
- **Messaging** — Zalo OA, Facebook Messenger, SMS, Web Chat
- **AI** — Voice AI (Vietnamese ASR), AI Callbot, AI QC, AI routing
- **Automation** — REST API, webhooks, n8n nodes, MCP Server
